# 🍋 Control de Stock por Pasillos - Mayorista LIMON

Sistema web liviano y rápido para el control y gestión de stock por pasillos y sectores en el salón y depósito del **Autoservicio Mayorista LIMON**.

## 🚀 Características
- **Organización por Pasillos:**
  - Pasillo 1: Limpieza
  - Pasillo 2: Almacén (Yerbas, Krachito, aderezos, etc.)
  - Pasillo 3: Bebidas (Gaseosas, aguas, energizantes)
  - Pasillo 4: Cerveza y Vino
- **Gestión de Stock en Tiempo Real:** Botones rápidos para sumar o restar bultos (+ / -).
- **Control de Vencimientos:** Alertas y fechas visibles por producto.
- **Bot Integrado:** Comandos rápidos por texto para actualizar inventario y buscar mercadería.
- **Exportación:** Generación de reportes listos para Excel.
- **Almacenamiento Local:** Los datos se guardan directamente en el navegador del dispositivo (`localStorage`).
